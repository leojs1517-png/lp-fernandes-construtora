# 🏛️ Fernandes Construtora - Ponta Porã (MS)

Website institucional e comercial interativo de alto padrão desenvolvido com tecnologias web modernas (Three.js 3D, GSAP, CSS Moderno e Simulador Caixa Minha Casa Minha Vida).

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico & Acessibilidade**
- **CSS3 Moderno**: Custom properties, Glassmorphism, CSS Grid, Flexbox, Microanimações e Design Responsivo
- **Three.js (r128)**: Render 3D interativo da maquete arquitetônica no Hero com 3 modos de iluminação (Blueprint, Dia e Noite)
- **GSAP 3 & ScrollTrigger**: Animações de entrada, transições fluidas e contadores numéricos
- **Simulador Oficial Minha Casa Minha Vida**: Algoritmo com regras e faixas de renda oficiais da Caixa Econômica Federal e integração com WhatsApp
- **Lucide Icons**: Ícones vetoriais modernos e leves

## 🏢 Empreendimentos em Destaque

1. **Residencial Fronteira Nobre**: Casas inteligentes contemporâneas de alto padrão
2. **Parque das Acácias**: Minha Casa Minha Vida Premium com subsídio Caixa
3. **Edifício Grand Horizon**: Torre residencial vertical panorâmica no centro de Ponta Porã
4. **Reserva Ponta Porã**: Lotes e casas em condomínio fechado de alto luxo
